# OLED Display Interface on Basys3 FPGA

## 📌 Overview
This project demonstrates how to interface an **SSD1306 OLED display** with the **Basys3 FPGA board** using **Verilog HDL**.  
It covers initialization, data transfer, and rendering simple graphics/text on the OLED screen.

## 🛠️ Hardware Requirements
- **Basys3 FPGA Board** (Xilinx Artix-7)
- **SSD1306 OLED Display** (I2C/SPI based, 128x64 resolution)
- Breadboard and jumper wires
- USB cable for programming
